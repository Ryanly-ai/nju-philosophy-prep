# 论述题训练

**启用时间**：2026-10-01 起（冲刺阶段）
**用途**：针对 673 哲学综合（5 道全必做论述）+ 912 中哲论述题

## 目录约定

按 "**YYYYMMDD_题号_题干关键词.md**" 命名，例如：
- `20261005_q1_仁爱与兼爱.md`
- `20261012_q2_格物致知的演变.md`

## 单题文件模板

```markdown
# 题目
（完整题干）

# 我的答题（限时 30-40 分钟）
（正文）

# Claude 批改
## 优点
## 问题
## 缺失要点
## 分数评估（参照 20 分制）
## 改写示范段落

# 二次修订
（根据反馈重写关键段落）

# 关联考点
- 横向：相关命题
- 纵向：同一哲学家的其他命题
```

## 训练节奏建议

- 10 月：每周 2 题（混合中西马）
- 11 月：每周 3 题，最后两周模拟整卷
- 12 月：押题方向为主，不求新题

## 题库来源

1. 南大历年真题（914/912 + 673 / 旧版哲学综合）
2. 兄弟院校（北大、复旦、武大）真题中可迁移的题
3. 学长经验贴中提到的高频考点

## 答题框架储备

在训练期同步产出几个"万能脚手架"：
- 人物类：生平 → 核心概念 → 主要命题 → 论证结构 → 学派地位 → 思想史影响
- 概念类：词源 → 前人语境 → 本家独特含义 → 论证 → 命题群 → 现代价值
- 比较类：背景对照 → 问题意识差异 → 核心主张差异 → 论证方式差异 → 历史命运
- 史料学类：版本 → 作者归属 → 内容划分 → 主要思想 → 研究状况
