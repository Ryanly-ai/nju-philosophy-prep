# Anki 卡片生成目录

## 目录约定

按 "**编号_主题**" 组织，例如：
- `01_先秦早期.json`（导论 + 孔孟老庄墨等）
- `02_先秦晚期.json`（荀子、韩非子、名家）
- `03_汉代哲学.json`
- `04_魏晋玄学.json`
- ... 依此类推

## 卡片格式（推荐）

每张卡片是 JSON 对象，便于 AnkiConnect 推送：

```json
{
  "deckName": "南大中哲",
  "modelName": "基本",
  "fields": {
    "Front": "问题 / 概念 / 原文",
    "Back": "答案 / 解释 / 出处与释义"
  },
  "tags": ["先秦", "老子", "道论"]
}
```

## 卡片类型（按题型反推）

| 类型 | 正面 | 背面 | 对应考题 |
|---|---|---|---|
| **概念** | "逍遥" | 庄子哲学中……定义/要点/出处 | 912 论述、673 论述 |
| **命题** | "反者道之动" | 出自《老子》40 章……含义/地位 | 912 出处、论述 |
| **原文填空** | "子曰：笃信好学，____ " | 守死善道 | 912 原著填空 |
| **人物比较** | "孔子仁爱 vs 墨子兼爱" | 差异要点 3-5 条 | 912 / 673 论述 |
| **出处题** | "苟日新，又日新，日日新" | 《礼记·大学》（商汤盘铭） | 912 作者出处 |
| **史料学** | "郭店楚简《五行》" | 1993 年湖北郭店一号楚墓出土……与子思关系 | 912 论述·史料学 |

## 卡片产出标准（每章硬上限）

| 书 / 章 | 硬上限 | 说明 |
|--------|------:|------|
| 郭齐勇《中哲史》大章（孔、老、孟、庄、朱、王阳明等）| **15 张** | 超过必须砍 |
| 次要章节（名家、阴阳家、告子、董仲舒支系等）| 5-8 张 | |
| 精读期《老子》《庄子》等原文 | 每篇 3-6 张 | 以金句填空为主 |

**每张卡必须满足**：
1. 瞄准 912/673 真题题型（名词解释/论述/原文填空/出处/比较）
2. 背面可在考场 1-2 分钟内凭记忆复现
3. 与同章其他卡不重复核心命题

**超出上限的处理**：移入 `备考规划/读书笔记/{书名}/` 作为笔记，不上 Anki。

## 🔔 Bark 随机抽查推送（2026-04-30 配置）

每天 7:00 - 22:00 每小时整点，随机抽一张「已学过」的郭齐勇标准卡组卡片推送到手机 Bark。

### 文件
- `anki_bark_push.py` — 抽卡 + 推送脚本（带 `--dry-run` 调试 / `--reset` 清当日去重）
- `~/Library/LaunchAgents/com.ryan.anki-bark-push.plist` — launchd 调度（不在 repo 内）

### 行为约定
- 抽卡范围：`deck:"中哲::《中国哲学史》——郭齐勇::*" -is:new`（仅已学过的标准卡组）
- 加权：标签 `#高频` 的卡权重 ×2
- 去重：当日已推过的不重复抽（`/tmp/anki_bark_pushed_today.json`）
- 跨日自动重置；当日全部轮一遍后也自动重置
- 必须 Anki App 在线（占用 8765 端口），否则跳过当次

### 常用命令
```bash
# 手工抽一张到手机
python3 ~/Desktop/哲学史/备考规划/Anki生成/anki_bark_push.py

# 干跑（只打印不推送）
python3 ~/Desktop/哲学史/备考规划/Anki生成/anki_bark_push.py --dry-run

# 清空当日去重记录（强制下次能抽到任意卡）
python3 ~/Desktop/哲学史/备考规划/Anki生成/anki_bark_push.py --reset

# 暂停 / 恢复 launchd 推送
launchctl unload ~/Library/LaunchAgents/com.ryan.anki-bark-push.plist
launchctl load   ~/Library/LaunchAgents/com.ryan.anki-bark-push.plist

# 看运行日志
tail /tmp/anki_bark_push.out.log /tmp/anki_bark_push.err.log
```
