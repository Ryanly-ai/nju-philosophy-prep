# Anki 卡片生成目录

## 目录约定

按 "**编号_主题**" 组织，例如：
- `01_先秦早期.json`（导论 + 孔孟老庄墨等）
- `02_先秦晚期.json`（荀子、韩非子、名家）
- `03_汉代哲学.json`
- `04_魏晋玄学.json`
- ... 依此类推

## 卡片格式（推荐）

每张卡片是 JSON 对象，便于 AnkiConnect 推送：

```json
{
  "deckName": "南大中哲",
  "modelName": "基本",
  "fields": {
    "Front": "问题 / 概念 / 原文",
    "Back": "答案 / 解释 / 出处与释义"
  },
  "tags": ["先秦", "老子", "道论"]
}
```

## 卡片类型（按题型反推）

| 类型 | 正面 | 背面 | 对应考题 |
|---|---|---|---|
| **概念** | "逍遥" | 庄子哲学中……定义/要点/出处 | 912 论述、673 论述 |
| **命题** | "反者道之动" | 出自《老子》40 章……含义/地位 | 912 出处、论述 |
| **原文填空** | "子曰：笃信好学，____ " | 守死善道 | 912 原著填空 |
| **人物比较** | "孔子仁爱 vs 墨子兼爱" | 差异要点 3-5 条 | 912 / 673 论述 |
| **出处题** | "苟日新，又日新，日日新" | 《礼记·大学》（商汤盘铭） | 912 作者出处 |
| **史料学** | "郭店楚简《五行》" | 1993 年湖北郭店一号楚墓出土……与子思关系 | 912 论述·史料学 |

## AnkiConnect 推送（冲刺前再实施）

1. 安装 Anki 桌面版 + AnkiConnect 插件
2. 启动 Anki，保持本地 8765 端口开放
3. Claude 读取此目录下 JSON，调用 AnkiConnect `addNotes` 接口批量推入

（本步骤在第一个月末 / 5 月中再做，前期先把卡片内容累积起来）
