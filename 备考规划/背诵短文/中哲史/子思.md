# 子思子 · 背诵短文

> **一句话识子思**：孔伋，字子思，**孔子之孙、孔鲤之子，曾子弟子，孟子私淑师承**。儒家"**思孟学派**"开创者，承前启后——上承孔子伦理，下启孟子心性。所传《中庸》朱熹列为"四书"之一；《五行》《缁衣》经马王堆帛书、郭店楚简重见天日，弥合**"孔→孟"**断层。考频上"被低估"：南大第一高频出处即出自《中庸》。

## 一、子思其人与作品 + 郭店楚简史料学 ⭐⭐⭐

### 其人

子思（前 483?—前 402?），名孔伋。孔子之孙、孔鲤之子，曾子弟子，孟子私淑师承。儒家"思孟学派"开创者。

### 作品系统

| 作品 | 文献位置 |
|------|---------|
| **《中庸》** | 《礼记》第 31 篇；朱熹列"四书"之一 |
| **《五行》** | 1973 马王堆汉墓帛书；1993 郭店楚简再出 |
| **《缁衣》** | 郭店楚简 / 上博简 / 今本《礼记》三见 |
| **《鲁穆公问子思》** | 郭店楚简 |
| **《表记》《坊记》** | 传为子思系作品 |

### 郭店楚简的意义

- 解决思孟学派与五行说归属——**证孟子前已有系统五行心性论**
- 弥合先秦儒学**"孔→孟"断层**
- 与马王堆《五行》对读，确证子思学派存在

**真题**：⭐⭐⭐ 2011 论述"郭店楚简"考过；南大史料学题偏爱郭店。

## 二、五行 —— 仁义礼智圣，心性论之"五行" ⭐⭐

### 区别于邹衍五行

子思《五行》**非"金木水火土"五行**，而是 **仁、义、礼、智、圣** 心性论之"五行"。
"圣"是子思五行独有德目——孔子、孟子四端皆未列"圣"。

### 德之行 vs 行（最重要区分）

| | 含义 |
|---|------|
| **德之行** | **形于内**——发自内心的自觉，属形而上的天道 |
| **行** | **形于外**——为迎合外界规范，未发自内心，属形而下的人道 |

——下学上达 / 内圣外王 / 内收 vs 外扩。

### 一心三思

| | 特征 | 所在 |
|---|------|------|
| **仁之思** | 精细 | 在体（内化德气流于颜面四肢） |
| **智之思** | 长久 | 在眼（发现贤人美德、与礼教相关） |
| **圣之思** | 轻盈 | 在耳（与乐道相关） |

**三心**：独心 / 中心 / 外心——"舍其体而独其心"。

### 思想史意义

- 五德目下贯孟子四端（仁义礼智）+ 强调"圣"
- "形于内"奠基儒家心性论
- 通过郭店、马王堆双重出土，恢复"**孔→子思→孟子**"一脉

## 三、《中庸》首章三命题 —— 形上学纲领 ⭐⭐⭐

> **"天命之谓性，率性之谓道，修道之谓教。"**——《中庸》开篇

### 三层贯通

| 命题 | 含义 |
|------|------|
| **天命之谓性** | 上天所赋本质属性，即人之"性"——**性源于天**，性善论的形上根据 |
| **率性之谓道** | 循性而行即"道"——**道在性中**，伦理日用即天道 |
| **修道之谓教** | 修治此道为社会规范，即"教"——**教从道出**，礼乐文明非外铄 |

### 哲学突破

- 把孔子"敬而远之"的天与人**内在打通**
- "**天命—性—道—教**"四级贯通：宇宙论 + 心性论 + 伦理学 + 教化论一气而成
- 先秦儒家最系统的形上学纲领

### 思想史影响

- 朱熹《中庸章句》以此为四书核心
- 程颐："**《中庸》，孔门传授心法**"
- 宋明理学"性即理"、王阳明"心即理"皆从此命题展开

## 四、中和 —— 体用框架，天人贯通 ⭐⭐⭐⭐⭐（南大第一高频）

> **"喜怒哀乐之未发，谓之中；发而皆中节，谓之和。中也者，天下之大本也；和也者，天下之达道也。致中和，天地位焉，万物育焉。"**——《中庸》第一章

### 中和定义

| | 状态 | 地位 |
|---|------|------|
| **中** | 情感**未发**——心寂然不动，无过与不及 | **道之体**、性之德——天下大本 |
| **和** | 情感发而**中节**——抒发恰到好处 | **道之用**、情之德——天下达道 |

### 致中和

> **"天地位焉，万物育焉。"**

——内在心性修养与宇宙化育相通；个体心性与天地万物贯通——**儒家"天人合一"最经典表述**。

### 哲学意义

| | 影响 |
|---|------|
| **体用框架** | 中（体）—和（用）开宋明理学体用论先河 |
| **未发已发** | 成为程颢、朱熹工夫论核心范畴 |
| **性情论** | 性发为情，情中节为善——奠定儒家性情结构 |

**真题**：⭐⭐⭐⭐⭐ "**致中和，天地位焉，万物育焉**" 912 出处题 **5 次考察**（2010 / 2011 / 2014 / 2015 / 2017）——**南大第一高频出处**。

## 五、诚 —— 天之道与人之道 ⭐⭐⭐（2025 真题刚考）

### 两层定义

> **"诚者，天之道也；诚之者，人之道也。"**

- **诚者**（天之道）——天的本然真实状态
- **诚之者**（人之道）——人通过工夫去契合天道

### 圣人 vs 学者

| | 特征 | 工夫 |
|---|------|------|
| **诚者**（圣人） | **不勉而中，不思而得，从容中道** | 本然合道 |
| **诚之者**（学者） | **择善而固执之者也** | 后天工夫 |

### 求诚五目

> **"博学之，审问之，慎思之，明辨之，笃行之。"**

### 至诚境界

- "**唯天下至诚为能化**"（2014/2015/2018 三考）
- "其次**致曲**，曲能有诚，诚则形，形则著，著则明，著则动，动则变，动则化"（**2025 填空考过**）
- 至诚则"可以**赞天地之化育**，可以**与天地参**"

### 诚明双向

> **"自诚明谓之性，自明诚谓之教。"**

- 由本体之诚自然光明（**圣人**）
- 由后天明察以达诚（**学者**）

### 思想史影响

- 周敦颐《通书》："**诚者，圣人之本**"
- 张载："诚明所知，乃天德良知"
- 朱熹："诚者，真实无妄之谓"
- 王阳明："良知即是诚"

**真题**：⭐⭐⭐ **2025 年 912 简答："简述《中庸》中关于'诚'的思想"刚考！**

## 六、戒慎慎独 —— 内省工夫之极致 ⭐⭐

> **"道也者，不可须臾离也，可离非道也。是故君子戒慎乎其所不睹，恐惧乎其所不闻。莫见乎隐，莫显乎微。故君子慎其独也。"**——《中庸》第一章

### 工夫两面

| | 对象 |
|---|------|
| **戒慎** | 未发未睹未闻者——心未起念时即收敛 |
| **慎独** | 独处或念头初动时，内心隐微之处的警觉 |

- "**莫见乎隐**"——隐处反而最显
- "**莫显乎微**"——微处反而最著
- **独知独觉之地，最见工夫**

### 哲学意义

- 把道德修养推到**意识最隐微的层面**——儒家内省工夫的极致
- 由"行"转向"心"——心学路径的开端
- 与"诚"工夫互为表里：诚是本体真实，慎独是工夫保任

### 思想史

- 《大学》"诚意慎独"承此
- 朱熹"主敬"工夫从慎独发展
- 王阳明"致良知"、刘宗周"慎独"立教皆本于此

**真题**：2009 出处"故君子戒慎乎其所不睹"考过。

## 七、《中庸》是怎样一部作品（论述题答案要点） ⭐⭐⭐

### 作者归属

传统说法为子思（孔伋）所作；宋以后疑古；现代学界倾向"**子思学派集体作品**"。

### 文献位置

原为《礼记》第 31 篇；朱熹与《大学》《论语》《孟子》合为"**四书**"。

### 五大主题

| 主题 | 命题 |
|------|------|
| **天命与性** | "天命之谓性，率性之谓道，修道之谓教" |
| **中和** | 未发已发体用框架——"致中和，天地位焉，万物育焉" |
| **诚** | "诚者天之道，诚之者人之道" |
| **慎独工夫** | "君子戒慎乎其所不睹" |
| **圣人境界** | "唯天下至诚为能化"——人与天地参 |

### 哲学突破

- 完成孔子伦理学的**形上学化**
- "**性—道—教**"贯通：天人合一第一部系统论证
- 提出"诚"作为本体—工夫枢纽

### 朱熹评

"**始言一理，中散为万事，末复合为一理。**"

**真题**：2009 已考"《中庸》是怎样一部作品"；2024 考过"《大学》主要思想"——同题型。

> **博学审问慎思明辨笃行**，**致曲**渐进至化境。

> **莫见乎隐**，**慎独**为工夫之极。

> 子思之学，**承孔启孟**，
> 思孟学派——开宋明心性之门。
