# 庄子 · 背诵短文

> **一句话识庄**：庄周，蒙人，战国中期道家代表，著《庄子》（亦称《南华经》）。承老子之"道"而**化为境界**——道家由"**治术之道**"（老）转向"**心灵之道**"（庄）；由"无为而治"转向"逍遥而游"。文体即哲学——以"**寓言、重言、卮言**"言道之不可言。学长原话："翻译题大范围跑不出先秦和宋明……庄子是翻译题的命脉。"

---

## 一、庄子之"道" —— 五大特性 + 与老子之异 ⭐⭐⭐

### 五大特性

| | 命题 |
|---|------|
| **本源性** | "**自本自根，未有天地，自古以固存**"（《大宗师》） |
| **普遍性** | 大无不包，细无不入——"在蝼蚁""在稊稗""在瓦甓""**在屎溺**"（《知北游》） |
| **整体性** | 通贯万物，无分裂——其特性是"**通**" |
| **自本自根** | 不依任何事物 |
| **不可言说** | 感官知性不及，但可由生命体证 |

### 与老子之异

| | 老子 | 庄子 |
|---|------|------|
| 道之性格 | 本源 + 法则 | 境界 + 体证 |
| 侧重 | 宇宙生成 / 治术 | 个体精神 / 主体内化 |
| 求 | **无为而治** | **逍遥而游** |

**思想史定位**：道家由"**治术之道**"转向"**心灵之道**"。

---

## 二、道通为一 ⭐⭐⭐（《齐物论》核心命题）

> **"故为是举莛与楹，厉与西施，恢恑憰怪，道通为一。"**——《齐物论》

### 三齐

| | 命题 |
|---|------|
| **齐是非** | "是亦彼也，彼亦是也。彼亦一是非，此亦一是非" |
| **齐物我** | "**天地与我并生，万物与我为一**" |
| **齐生死** | "方生方死，方死方生" |

### 方法

> "**枢始得其环中，以应无穷**"——立**道枢**之位。

**真题**：⭐⭐⭐ 2008、2014 翻译联动；2018 翻译"可乎可，不可乎不可…道通为一"；2016 简析"正处、正味、正色"。

## 三、坐忘 / 心斋 / 吾丧我 —— 修养三联 ⭐⭐⭐（2024 真题）

### 坐忘（《大宗师》）

> **"堕肢体，黜聪明，离形去知，同于大通，此谓坐忘。"**

颜回工夫**三阶**：忘仁义 → 忘礼乐 → 坐忘。

### 心斋（《人间世》）

> **"气也者，虚而待物者也。唯道集虚。虚者，心斋也。"**

**三层听**：耳 → 心 → 气。
**核心**：**虚**。

### 吾丧我（《齐物论》）

> "**今者吾丧我**"——丧偏私小我，存合道大我。

### 共同特征

**否定式工夫**——忘、丧、虚——与老子"**为道日损**"同一进路。

**思想史**：直通玄学言意之辨 / 禅宗破执 / 宋明静坐。

**真题**：⭐⭐⭐ **2024 简答："分析庄子的'坐忘'思想"刚考**。

## 四、逍遥 + 三无 —— 至人、神人、圣人 ⭐⭐

> **"至人无己，神人无功，圣人无名。"**——《逍遥游》

### 逍遥

不受任何束缚的精神自由——
> "**乘天地之正，而御六气之辩，以游无穷。**"

### 三无

| | 含义 |
|---|------|
| **至人无己** | 超越自我中心 |
| **神人无功** | 不刻意建功 |
| **圣人无名** | 不求名声 |

### 三种逍遥（郭象注）

- 大鹏之大逍遥
- 学鸠之小逍遥
- **各适其性即逍遥**——"**安于命者，无往而非逍遥**"（2015 真题）

### 哲学意义

把人格理想从社会角色（儒）转向**精神境界**（庄）。

## 五、道枢 / 莫若以明 / 缘督以为经 —— 知论方法

### 破"成心"

> "道隐于小成，言隐于荣华。故有儒墨之是非。"

### 莫若以明

> "欲是其所非，而非其所是，则**莫若以明**"——以虚静明觉之心观照。

### 道枢 / 天钧

> "**枢始得其环中，以应无穷。**"——立于是非两端的中心点。

### 缘督以为经（《养生主》）

> **"缘督以为经，可以保身，可以全生。**"——持守中空之常道。

### 总结

提倡怀疑批判，但**非怀疑论**——目标是由小智上升到大智。

**真题**：2011 翻译联动"道枢"。

## 六、真人 —— 天人合一的人格典范 ⭐⭐

> **"古之真人，不知说生，不知恶死……是之谓不以心捐道，不以人助天。"**——《大宗师》

### 真人四特征

| | 内容 |
|---|------|
| ① | 不悦生不恶死——超越生死分别 |
| ② | 翛然往来——自由出入 |
| ③ | 受而喜之，忘而复之——任运自然 |
| ④ | **不以心捐道，不以人助天**——天人合一 |

### 理想人格谱系

**真人 / 至人 / 神人 / 圣人 / 天人**——五种名号同指一道家理想。

### 不以心捐道简析

- 心 vs 道：人心带成见欲望——会扭曲天道之本然
- 人 vs 天：人为造作的"善意干预"——往往违背自然
- 双重否定：去除主观意志，回归任运自然
- 真人之"真"——不假人为，与天合德

**真题**：2013 翻译"古之真人"+ 简析"不以心捐道"；2017 翻译"鱼相忘乎江湖"+ 简析"**畸人者，畸于人而侔于天**"。

## 七、三言 —— 寓言 · 重言 · 卮言

> "**寓言十九，重言十七，卮言日出，和以天倪。**"

| | 内容 |
|---|------|
| **寓言** | 通过故事讲道理（庖丁解牛、庄周梦蝶） |
| **重言** | 假借古圣名人之口（孔子、颜回、老聃） |
| **卮言** | 无心之言，随物婉转 |

**哲学意义**：与儒家"正名""立言"传统针锋相对——体现"**言无言**"，与"道不可言"呼应。**文体即哲学**。

**文学地位**：鲁迅评"晚周诸子之作，莫能先也"。

## 八、《齐物论》是怎样一部作品 ⭐⭐⭐（2012 真题）

### 篇章地位

《庄子》内篇第二，与《逍遥游》并列**双璧**——**逍遥游论境界，齐物论论认识**。

### 篇名双解

- 齐"物论"：齐同各家是非
- "齐物"论：万物齐一

### 五大主题

| | 内容 |
|---|------|
| **吾丧我** | 南郭子綦"形如槁木，心如死灰" |
| **三籁** | 天 / 地 / 人籁——万音皆出于自然 |
| **破成心** | "道隐于小成"——儒墨皆陷成心 |
| **道通为一** | 道枢应无穷 |
| **齐物三义** | 齐是非 / 齐物我 / 齐生死 |

### 方法论

莫若以明 / 道枢 / 两行。

### 著名寓言

朝三暮四 / 庄周梦蝶 / 罔两问景。

### 哲学意义

中国第一部系统的**认识论 + 怀疑论 + 相对主义**——启发玄学"得意忘言"、禅宗破执，亦可与维特根斯坦语言批判对话。

## 九、老庄比较 —— 道家内部的两次跃迁 ⭐⭐

**总框架**：老子立"道"于形上、庄子化"道"为境界——道家由**治术之道**转向**心灵之道**。

| 维度 | 老子 | 庄子 |
|------|------|------|
| 道的性格 | 道法自然（规律性） | 道通为一（齐同性） |
| 侧重 | 治术 | 心境 |
| 政治 | 无为而治 | 安于命无往非逍遥（遁世） |
| 主体 | 圣人（治者） | 真人 / 至人（自由人格） |
| 方法 | 为道日损 | 坐忘心斋（更彻底剥落） |
| 辩证法 | 反者道之动（对立转化） | 齐物（对立消融） |
| 风格 | 箴言体 | 寓言体 |

### 分流

- 老学：→ 黄老 → 法家（韩非）→ 道教
- 庄学：→ 魏晋玄学 → 禅宗 → 文人精神

### 与儒比较

儒：建构入世；老：解构治术；庄：超脱出世——**三足鼎立**。

## 🎯 速记口诀（朗诵版）

> 庄子之**道**——自本自根，**在屎溺**亦**在瓦甓**。
> **道通为一**——齐是非 · 齐物我 · 齐生死。
> **吾丧我**——形如槁木心如死灰；
> **心斋**虚而待物，**坐忘**同于大通。
> **逍遥**——**至人无己 · 神人无功 · 圣人无名**。
> **真人**——**不以心捐道，不以人助天**。
> 老主**治术**，庄主**心境**；
> 老损道日，庄忘坐通——
> 道家两峰，开境界之学。
