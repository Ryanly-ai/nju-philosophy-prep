# 荀子 · 背诵短文

> **一句话识荀**：荀况，赵人，游齐稷下三为祭酒，晚居楚兰陵。儒家三圣最后一位，开**个人著作体**先河。师承孔门而别开生面——孟子言"心性合一"以扩充四端，荀子则"心性二分"以化性起伪。法家韩非、李斯皆出其门，然荀子终是儒家立场。

---

## 一、人性论 —— 性伪之分，化性起伪 ⭐⭐⭐

荀子之"性"非孟子之"性"。一刀两断，先立"性伪之分"——

> **"不可学、不可事之在天者，谓之性；可学而能、可事而成之在人者，谓之伪。"**——《性恶》
> **"性者，本始材朴也；伪者，文理隆盛也。"**——《礼论》

性是**天生本能**：饥欲饱、寒欲暖、好色好声好利；
伪是**人为礼义**：学之而能、事之而成。

性恶非性恶毒，乃**顺性必乱**。情欲不导则争，争则乱，乱则穷。故须——

**化性起伪**：圣人化性而起伪，伪起于性而生礼义，礼义生而制法度。——《性恶》

四条路径：
- ① 教化以**学**之——"今人之性，固无礼义，故强学而求有之也"
- ② 礼法以**制**之——国家刑罚、社会规范
- ③ 习俗以**积**之——"注错习俗"
- ④ 心君以**宰**之——以理性（心/天君）支配感性（天官）

终极目标："**性伪合而天下治**"，**涂之人可以为禹**——凡夫皆可成圣。

### 孟荀人性论对照 ⭐⭐⭐（论述高频）

|     | 孟子 · 性善 | 荀子 · 性恶 |
|-----|------------|------------|
| 性 | 四端善端，仁义礼智 | 情欲本能，饥寒好利 |
| 善源 | 先天固有 | 后天习得 |
| 修养 | 存心养性，扩充四端 | 化性起伪，改造本性 |
| 气质 | 理想主义 | 现实主义 |
| 心性 | **合一**（心即性） | **二分**（心可虑性） |

张岱年一语点透：**孟荀所谓"性"非同一事**，定义不同，故未尝不可相容。

## 二、天人论 —— 天行有常，制天命而用之 ⭐⭐⭐

三层递进，一气贯通：**有常 → 分职 → 制用**。

### 第一层：天行有常

> **"天行有常，不为尧存，不为桀亡。应之以治则吉，应之以乱则凶。"**——《天论》

日月星辰，禹桀皆同；治乱在人，不在天。
由此破迷信：求雨不必、卜筮不灵；祭祀不过表"思慕"，是"人道"非"鬼事"。

### 第二层：明于天人之分

> **"天有其时，地有其财，人有其治。"**
> "天能生物，不能辨物；地能载人，不能治人。"
> **"人之命在天，国之命在礼。"**

正反对照：
- 强本节用 → 天不能贫；养备动时 → 天不能病；循道不贰 → 天不能祸。
- 本荒用侈 → 天不能富；倍道妄行 → 天不能吉。

"受时与治世同，而殃祸异——**不可以怨天**。"

### 第三层：制天命而用之

> **"大天而思之，孰与物畜而裁之？从天而颂之，孰与制天命而用之？"**——《天论》
> "错人而思天，则失万物之情。"

六组反问，递进而出：与其迷信天，不如蓄养利用；与其歌颂天，不如掌握驾驭；与其等待时，不如因应势。

**思想高度**：先秦罕见的**人的主体能动性**。与孟子"知天""畏天"不同——荀子**尊天而不畏天，知天而能为天**。

## 三、礼论 —— 礼有三本，明分使群 ⭐⭐⭐

### 礼的起源（论述高频）

> **"人生而有欲，欲而不得则不能无求，求而无度量分界则不能不争。争则乱，乱则穷。先王恶其乱也，故制礼义以分之。"**——《礼论》

逻辑链条：**欲 → 求 → 争 → 乱 → 穷 → 礼**。
核心矛盾：**人之无限欲 vs 物之有限供**。
解决方案：**使欲必不穷乎物，物必不屈于欲，两者相持而长**。

注意：性恶论是礼论的**逻辑前提**——正因人性恶，才需礼义来教育、改造、制约。

### 礼有三本 ⭐⭐⭐（名词解释高频）

> **"礼有三本：天地者，生之本也；先祖者，类之本也；君师者，治之本也。"**——《礼论》
> "三者偏无，焉无安人。"

|本| 含义 | 礼俗 |
|---|------|------|
| 天地 | 生命的本源 | 祭天地 |
| 先祖 | 族类的本源 | 祭祖 |
| 君师 | 政治的本源 | 尊君师 |

人有根源感 → 眷怀追思 → 演为礼制 → 安定人心、秩序社会。

### 明分使群 ⭐⭐

人与动物之别在于能**群**，人之能群在于能**分**，分之能行在于**义**。

> **"人能群，彼不能群也。人何以能群？曰：分。分何以能行？曰：义。"**——《王制》
> **"君者，能群也。"**——《君道》

义分则和 → 和则一 → 一则多力 → 多力则强 → 强则胜物。
群而无分 → 争 → 乱 → 离 → 弱。

"救患除祸，则莫若**明分使群**矣。"——《富国》

## 四、礼乐论 —— 礼别异，乐合同 ⭐⭐

> **"乐合同，礼别异，礼乐之统，管乎人心矣。"**——《乐论》

- **礼**主**分**：定等差、立秩序、别尊卑
- **乐**主**合**：和情志、同人心、融上下

"礼乐刑政，其极一也，所以**同民心而出治道**也。"

荀子主张"**美善相乐**"——以雅乐陶冶性情、纯洁人心，反对靡靡之音。

## 五、礼治 vs 法治 —— 师弟之别 ⭐⭐

韩非、李斯出于荀门，然荀子终是**儒家**：

|         | 荀子 · 礼治 | 法家 · 法治 |
|---------|------------|------------|
| 本     | 仁义道德 | 赏罚刑名 |
| 法     | **"法者治之端，君子者法之原"**——以法辅礼 | 以法为教，以吏为师 |
| 人     | "有乱君无乱国，**有治人无治法**" | "不恃人之以爱为我" |
| 教     | 礼乐成人格 | 严家无悍虏 |
| 标     | 和乐庄敬 | 富国强兵 |

师弟分野的关键：**礼义是社会认同的道义原则**，而非纯粹君主集权工具。

## 六、正名 —— 制名之枢要 ⭐⭐

《荀子·正名》五条原则：

| # | 原则 | 要义 |
|---|------|------|
| ① | **约定俗成** | "名无固宜，约之以命，约定俗成谓之宜"——名的社会性 |
| ② | **同则同之，异则异之** | 名依据实，物同名同 |
| ③ | **单/兼/共名** | 单足喻则单（马），不足则兼（白马），同类则共（牛） |
| ④ | **大共名/大别名** | 物为大共名（推而共之），鸟兽为大别名（推而别之） |
| ⑤ | **稽实定数** | 状同所异为二实，状变所同为一实（化） |

## 七、解蔽 —— 蔽于用而不知文 ⭐⭐（11 年原题）

凡蔽皆生于片面，圣人**兼陈万物而中悬衡**。
心要**虚壹而静**，方能"大清明"。

荀子论诸子之蔽：
- 墨子"**蔽于用而不知文**"——重实用而失礼乐文饰（11 年南大原题）
- 庄子"蔽于天而不知人"
- 申子"蔽于势而不知知"
