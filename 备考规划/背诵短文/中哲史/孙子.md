# 孙子 · 背诵短文

> **一句话识孙**：孙武，齐人，春秋末年兵家代表，著《孙子兵法》十三篇。中国第一部系统兵学经典，亦是先秦哲学辩证思维的兵学应用。其"道""势""奇正""虚实"诸范畴，**与老子辩证法同源异流**——老子论自然之反，孙子论人为造势。

---

## 一、经之以五事，校之以计 —— 战争哲学总纲

> "**兵者，国之大事，死生之地，存亡之道，不可不察也。**"——《计》开篇

**五事**：决定战争胜负的五大要素

| | 含义 |
|---|------|
| **道** | 战争正义性／民众支持／上下同心——"令民与上同意也" |
| **天** | 阴阳寒暑、时制——气候时令 |
| **地** | 远近、险易、广狭、死生 |
| **将** | **智 · 信 · 仁 · 勇 · 严**——将帅五德 |
| **法** | 曲制、官道、主用——组织编制规章 |

**七计**：主孰有道？将孰有能？天地孰得？法令孰行？兵众孰强？士卒孰练？赏罚孰明？

**哲学注**："道"为五事之首——既指狭义政治正义，亦指广义战争客观规律。孙子"道"与老子"道"分属**应用与本体两层**，但同属春秋"道"范畴泛化的产物。

## 二、兵者诡道，虚实奇正 —— 军事辩证法

### 诡道

> "**兵者诡道也。能而示之不能……攻其无备，出其不意。**"——《计》

### 避实击虚

> "**夫兵形象水……兵之形避实而击虚。兵无常势，水无常形，能因敌变化而取胜者谓之神。**"——《虚实》

### 奇正相生

正面相对、出奇制胜的统一——"**奇正之变，不可胜穷**"。

### 治军四治（《军争》）

| | 内容 |
|---|------|
| **治气** | 避其锐气，击其惰归 |
| **治心** | 以治待乱，以静待哗 |
| **治力** | 以近待远，以佚待劳，以饱待饥 |
| **治变** | 无邀正正之旗，勿击堂堂之阵 |

**对立转化**：
> "**乱生于治，怯生于勇，弱生于强。**"——与老子辩证法同源。

## 三、任势 —— "势"论 ⭐

> "**激水之疾，至于漂石者，势也……善战者，求之于势，不责于人……如转圆石于千仞之山者，势也。**"——《势》

**势之含义**：位势、动势、能量、运动趋势。

**因利制权**："**势者，因利而制权也。**"

**与老子比较**：
- 老子"反者道之动"——重**自然之反**
- 孙子"任势"——重**人为造势**
- 以小博大、以弱胜强皆赖此

**思想史**："势"成为中国政治哲学核心范畴：
- 法家慎到"乘势"
- 韩非"势位"
- 宋明"理势合一"

——皆从孙子兵学借入。

## 四、知彼知己，上兵伐谋 —— 用兵最高原则

### 知胜五条（《谋攻》）

知可战不可战 / 识众寡之用 / 上下同欲 / 以虞待不虞 / 将能而君不御

### 知彼知己

> "**知彼知己，百战不殆。**"——《谋攻》
> "**知彼知己，胜乃不殆；知天知地，胜乃可全。**"——《地形》

**四知**：彼／己／天／地——层层递进。

### 全胜思想

> "**百战百胜，非善之善者也；不战而屈人之兵，善之善者也。**"——《谋攻》

### 上兵伐谋

> "**上兵伐谋，其次伐交，其次伐兵，其下攻城。**"——《谋攻》

**政治外交 优先于 军事**。

**哲学意义**：认识论与实践论的早期统一——中国哲学**"知行"传统**在兵学中的形态。
