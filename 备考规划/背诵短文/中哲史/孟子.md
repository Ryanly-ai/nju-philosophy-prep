# 孟子 · 背诵短文

> **一句话识孟**：孟轲，字子舆，邹人，受业于子思之门人，**继孔子之后儒家最重要的代表**，被尊为"亚圣"。承"思孟学派"心性论，立**性善论**与荀子"性恶"对峙。提出"**万物皆备于我**""**民贵君轻**""**舍生取义**"——奠定儒家心学路径与民本主义。韩愈"道统"列其为孔子嫡传，宋以后《孟子》入"四书"。

---

## 一、性善论 + 四端 ⭐⭐⭐（论述高频）

### 背景

战国人性论纷争——告子（性无善无不善）、世硕（有性善有性不善）、无名氏（性可善可不善）多说并起，孟子立性善论**独树一帜**。

### 核心命题

> **"人之所以异于禽兽者几希，庶民去之，君子存之。"**

人之异于动物者，**道德性**也。

### 四端 · 四心（《公孙丑上》）

| 端 | 之端 |
|---|------|
| **恻隐之心** | 仁之端 |
| **羞恶之心** | 义之端 |
| **辞让之心** | 礼之端 |
| **是非之心** | 智之端 |

> **"人之有是四端也，犹其有四体也。"**

### 性命题

> **"乃若其性，则可以为善矣，乃所谓善也。"**——《告子上》（2014 真题）

- 不善是"**放其良心**"——故须"**求其放心**"。
- **论证方法**：道德直觉——见孺子将入井，皆有怵惕恻隐之心。

### 思想史地位

- 中哲史上第一次明确揭示"**道德性是人之特性**"
- 与荀子"性恶"对峙，构成先秦人性论**双峰**
- 宋明理学"性即理""心即理"皆从此出

## 二、良知良能 + 大体小体 ⭐⭐⭐

### 良知良能

> **"人之所不学而能者，其良能也；所不虑而知者，其良知也。"**——《尽心上》

- 孩提之童无不知爱其亲——**爱亲即仁**
- 及其长也无不知敬其兄——**敬兄即义**
- **仁义为先天本有**

### 大体 vs 小体（《告子上》）

| | 含义 |
|---|------|
| **大体** | 心之官——"**心之官则思**" |
| **小体** | 耳目之官——"不思而蔽于物" |

> **"从其大体为大人，从其小体为小人。"**

### 先立乎其大者（2018 真题）

> **"先立乎其大者，则其小者不能夺也，此为大人而已矣。"**

### 天爵 vs 人爵

| | 内容 |
|---|------|
| **天爵** | 仁义忠信、乐善不倦——**内在道德** |
| **人爵** | 公卿大夫——**外在功名** |

"古之人**修其天爵而人爵从之**"——以德抗位。

### 思想史

- ⭐⭐⭐ **王阳明"致良知"直接承袭——2024 真题**
- 陆九渊"心即理"、王阳明"心外无理"皆此脉

## 三、浩然之气 + 知言养气 ⭐⭐

> 《公孙丑上》——"**我善养吾浩然之气**"

### 浩然之气

> **"其为气也，至大至刚，以直养而无害，则塞于天地之间。其为气也，配义与道；无是，馁也。"**

### 养法三条

| | 内容 |
|---|------|
| **集义所生** | 长期道德实践积累，非偶然外取 |
| **勿忘勿助** | 警惕揠苗助长 |
| **持志养气** | **"夫志，气之帅也；气，体之充也。"** |

### 知言

辨识偏颇言论——
- 诐辞知其所**蔽**
- 淫辞知其所**陷**
- 邪辞知其所**离**
- 遁辞知其所**穷**

### 知言养气一体

以"道德心"为枢纽——知言辨志，养气立志。

**哲学意义**：个人道德人格与宇宙真理贯通——**道德形上学初步**。启示宋明"涵养须用敬"、王阳明"致良知"工夫。

## 四、仁政 · 王道 · 民贵君轻 ⭐⭐⭐（政治哲学核心）

### 仁政

> **"仁政必自经界始。"**——《滕文公上》（2017 真题）
> "制民之产……乐岁终身饱，凶年免于死亡；然后驱而之善。"

发展孔子"庶富教"——**先富后教**。

### 王道 vs 霸道

| | 内容 |
|---|------|
| **王道** | "**以德行仁者王**" |
| **霸道** | "**以力假仁者霸**" |

> "**以力服人者非心服，以德服人者中心悦而诚服。**"

### 民贵君轻

> **"民为贵，社稷次之，君为轻。"**——《尽心下》

先秦民本主义最响亮的口号。

- "**得天下有道：得其民，斯得天下矣。**"——《离娄上》（2016 真题）
- "**闻诛一夫纣矣，未闻弑君也。**"——汤武革命合法性

### 思想史地位

- 中国民本主义最早系统表述
- 黄宗羲、谭嗣同皆从此承
- 与法家"君本"对峙

## 五、大丈夫 —— 富贵不能淫 ⭐⭐

> **"富贵不能淫，贫贱不能移，威武不能屈，此之谓大丈夫。"**——《滕文公下》

### 三立心

> **"居天下之广居（仁），立天下之正位（礼），行天下之大道（义）。"**

### 两得

> **"得志，与民由之；不得志，独行其道。"**

——后世"**达则兼济天下，穷则独善其身**"之源。

### 舍生取义

> **"生，亦我所欲也；义，亦我所欲也。二者不可得兼，舍生而取义者也。"**

### 思想史地位

- 中国知识分子精神人格的最高典范
- 文天祥"留取丹心照汗青"、谭嗣同"我自横刀向天笑"皆此脉
- 与孔子"君子"互补：**温柔敦厚 vs 刚毅卓绝**
- 后世"气节""风骨"观念的源头

## 六、万物皆备于我 · 尽心知性知天 ⭐⭐⭐（天人贯通）

### 万物皆备于我

> **"万物皆备于我矣。反身而诚，乐莫大焉。强恕而行，求仁莫近焉。"**——《尽心上》（2009 填空）

### 尽心知性知天

> **"尽其心者，知其性也；知其性，则知天矣。存其心，养其性，所以事天也。"**——《尽心上》

**三阶递进**：**心 → 性 → 天**

### 天人贯通的两路径

| 路径 | 命题 |
|------|------|
| **由内而外** | 尽心 → 知性 → 知天 |
| **由外内化** | 万物皆备于我 → 反身而诚 |

### 哲学意义

- 孔子"敬而远之"的天，在孟子这里通过心性内贯而成**可知可达之天**
- 把《中庸》"天命之谓性"具体化为修养工夫
- 为宋明"心即理""性即理"奠定根基

**真题**：⭐⭐⭐ **"莫之为而为者，天也；莫之致而至者，命也" 2011/2012/2013 三考**。

## 七、求放心 · 反身而诚 —— 修养工夫 ⭐⭐

> **"仁，人心也；义，人路也。舍其路而弗由，放其心而不知求，哀哉！……学问之道无他，求其放心而已矣。"**——《告子上》

### 核心

人本有善心，因物欲遮蔽而"放"失，**修养就是找回失落的本心**。

### 方法四条

| | 内容 |
|---|------|
| **反身而诚** | 内省至诚 |
| **切己自反** | 反躬自问 |
| **先立乎其大者** | 立心之主宰 |
| **寡欲** | "**养心莫善于寡欲**" |

### 夜气说（2023 真题翻译）

> "**其日夜之所息，平旦之气**"——清晨未与外物接触时的清明之气，即良心残余。

**牛山之木**双重比喻：山林之木被斧斤伐之 → 人之良心被欲望伐之；山犹有夜气复生 → 人犹有平旦之气可保。

### 哲学意义

把儒家修养论从"行为规范"推进到"**本心保任**"——为宋明"存天理灭人欲"、王阳明"致良知"奠基。

## 八、孟子对孔子仁学的继承与发展 ⭐⭐⭐（2025 真题刚考）

### 六维继承

- 仁爱核心
- 礼乐传统
- 君子人格
- 天命观
- 教化路线
- 学思方法

### 六维发展

| | 孔子 | 孟子 |
|---|------|------|
| 仁 | 仁内礼外 | 仁义并称 + 四端心性 |
| 性 | 性相近也，习相远也 | 性善论系统化 |
| 天 | 敬而远之 | 尽心知性知天 |
| 政治 | 为政以德 | 仁政民本——民贵君轻 |
| 人格 | 君子温柔敦厚 | 大丈夫刚毅卓绝 |
| 工夫 | 学思忠恕 | 求放心 + 浩然之气 |

**整体定位**：孟子在孔子"内在转向"基础上完成**心性论的系统化**——上承子思、下启宋明，立**心学路径**。
