# 惠子与公孙龙子 · 背诵短文

> **一句话识名家**：先秦诸子中**唯一以逻辑—语言为研究对象**的学派，俗称"辩者"。惠施代表**辩证的关系逻辑**，重事物相对性、同一性；公孙龙代表**概念分析与共相论**，重概念确定性、不矛盾性。与儒家"正名"传统不同——独立研究**名实问题**，开中国逻辑学先河。墨家《墨经》、荀子《正名》皆与之对话或批评。

---

## 一、惠施"历物十事" ⭐⭐⭐（名家辩证法代表）

惠施十大命题，保存于《庄子·天下》。

### 核心命题

| 命题 | 要义 |
|------|------|
| **至大无外，谓之大一；至小无内，谓之小一** | 宏观 / 微观的**无限性** |
| **天与地卑，山与泽平** | 空间相对性 |
| **日方中方睨，物方生方死** | 时间 / 运动的矛盾 |
| **大同而与小同异**（小同异）<br>**万物毕同毕异**（大同异） | 同异辩证 |
| **泛爱万物，天地一体也** | 整体观 |

### 特点

- 强调世界**整体性与普遍联系**
- 运用**关系逻辑**（非亚氏一元谓词逻辑）
- 重视空间、时间的**相对性与流动性**
- 是**辩证的关系逻辑**

### 与庄子关系

惠施为庄子至交，《庄子》中多次出现濠梁之辩、"子非鱼"等对话。惠施学问"**散于万物而不厌**"——但庄子评其"逐万物而不返"。

## 二、白马非马 ⭐⭐⭐（公孙龙最著名命题，论述高频）

> **"马者，所以命形也；白马者，所以命色也。命色者非命形也，故曰白马非马。"**——《白马论》

### 内涵论证

- **马**——只含形体规定
- **白马**——兼含颜色规定
- 内涵不同 → "白马非马"

### 外延论证

- 求**马**——黄、黑马皆可致
- 求**白马**——黄、黑马不可致
- 外延广狭不同，**种属关系**有别

### "非"的含义

| | 含义 |
|---|------|
| **公孙龙之"非"** | "有异"——非完全否定包含关系 |
| **常识误读** | "全异"——以为公孙龙否认白马是马 |

公孙龙**承认**"白马是（属于）马"的逻辑包含关系，但强调"白马异于马"的概念区分。

### 哲学意义

- 从**外延与内涵**两方面论证**一般与特殊、属名与种名**在指谓对象和属性上不相等
- 肯定不同概念的**确定性与不矛盾性**
- 中国第一次明确区分**普遍与特殊**的逻辑分析

## 三、坚白石二（坚白论）⭐⭐

> **"坚白石二，非坚白石三。"**——《坚白论》

### 论证

| 感官 | 所得 | 结论 |
|------|------|------|
| **看** | 白色（不见坚硬） | 二者（白 + 石） |
| **摸** | 坚硬（不见白色） | 二者（坚 + 石） |

不同感官产生不同属性认识，"坚"与"白"**相互独立、分离**（公孙龙称"**藏**"）。

### 深层含义

| 层 | 内容 |
|---|------|
| **事实层** | 坚白石是一块完整石头 |
| **语言分析层** | 坚性、白性、石性三种**抽象规定性**互相分离 |
| **共相论** | "坚""白"作为共相具有独立性，未与物相合时是隐藏的 |

体现**"既离又合"**的智慧——现象在特定关系中显现。

## 四、物莫非指，而指非指（指物论）⭐⭐

> **"物莫非指，而指非指。"**——《指物论》

### 核心范畴

- **指** = 概念 / 共相（指认、称谓之意）
- **物** = 实物 / 现象 / 个体

### 两命题

| 命题 | 含义 |
|------|------|
| **物莫非指** | 万物皆由概念来指谓，不存在不由"指"来指谓的"物" |
| **指非指** | 概念本身并不等于它所指谓的物 |

### 公孙龙强调概念独立性

- "物"对人来说，**在被概念 / 语言指谓时才有意义**
- "指"可分：抽象共相（白性、坚性）+ 物指（白马之白、坚白石之坚）

### 哲学意义

由**现象认识**进到**共相认识**，由**事实分析**进到**语言分析**——中国哲学第一次自觉的语言哲学转向。

## 五、公孙龙名实论 —— 物、实、位、正 ⭐⭐

> 《名实论》——名家的形上根基。

### 四范畴

| 范畴 | 含义 |
|------|------|
| **物** | 天地及其化生的万物 |
| **实** | 物之所以为物的本质属性（"形而上"的本体） |
| **位** | 使"实"得以为"实"的界限，保证"实"的定在 |
| **正** | 不出位、在其位 |

### 实的规定

对"实"的规定不能"**过**"——如欲知"马"之实，举"白马"则"过"了（白马含色规定，超出马的本质）。

### 正名的含义

**正名 = 正其所实** → "**离**"是"正"的前提（独立把握概念 / 共相）。

### 名实统一

名有独立性，凝结认知方式对共相的认识，反过来影响思维和生活。

## 六、公孙龙《通变论》—— 类的概念 ⭐

### 核心命题

> "**二有一乎？**" "**二无一！**"

复合概念一旦合成便**不可分割**——如"白马"既非"白"又非"马"。

### 分类原则

> "**羊合牛非马**"——羊牛有角，马无角 → 不同类。

- 类同须有共性
- 类异须以**同一特征之偏有偏无**为标准
- 不能只据表面特征，须依据**类之本质属性**

### 方法论

辨识建立在**标志性规定的区别**上，比较时应与**最相近的"名"**对比——如辨"牛羊"应与"马"比，不应与"鸡"比。

## 七、惠施与公孙龙比较 ⭐⭐（论述）

| 维度 | 惠施 | 公孙龙 |
|------|------|------|
| **核心方法** | 辩证的关系逻辑 | 概念分析与共相论 |
| **侧重** | 事物的相对性、同一性 | 概念的确定性、不矛盾性 |
| **代表命题** | "天与地卑""万物毕同毕异" | "白马非马""坚白石二" |
| **哲学贡献** | 揭示时空、同异的辩证性 | 区分一般与特殊、由现象进到共相 |
| **保存文献** | 《庄子·天下》（无独立著作传世） | 《公孙龙子》传世六篇 |

### 共同点

均属**名家**，重视概念辨析与逻辑推理；与儒家"正名"传统不同——**独立研究名实问题**。

### 《公孙龙子》传世六篇

| 篇 | 内容 |
|---|------|
| 《迹府》 | 门人辑录 |
| 《白马论》 | 白马非马 |
| 《指物论》 | 物莫非指 |
| 《通变论》 | 类的概念 |
| 《坚白论》 | 坚白石二 |
| 《名实论》 | 物实位正 |

## 八、名家的思想史地位

### 与儒道墨的对照

| | 立场 |
|---|------|
| **儒"正名"** | 价值优先（君君臣臣） |
| **道"无名"** | 道不可名 |
| **墨"三表"** | 经验真理标准 |
| **名家** | 概念分析、逻辑独立 |

### 后世评价

- 庄子：评惠施"逐万物而不返"——道家立场否定
- 荀子《正名》：批判"白马非马"为"惑于用名以乱名"——儒家立场否定
- 《墨经》：吸收名家逻辑成果，成为先秦逻辑最高峰

### 中绝原因

汉以后名家中绝——重价值轻逻辑的文化偏向 + 名家自身缺乏伦理政治关怀 + 玄学 / 佛学吸收其语言分析资源。
