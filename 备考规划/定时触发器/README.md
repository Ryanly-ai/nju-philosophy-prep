# 定时触发器说明

本目录存放 4 个云端 Claude agent 的 prompt 模板。每个触发器会在指定时间自动运行，并把结果推送到你的 Claude App 手机客户端。

## 触发器总览

| # | 文件 | Cron | 时间 | 用途 |
|---|---|---|---|---|
| 1 | `01_晨间任务清单.md` | `0 8 * * *` | 每天 08:00 | 根据周计划生成当日任务清单 |
| 2 | `02_晚间检视.md` | `0 20 * * *` | 每天 20:00 | 检视当日完成度，提醒填日志（周日此条变短） |
| 3 | `03_周日周计划.md` | `0 20 * * 0` | 周日 20:00 | 周回顾 + 生成下周计划（与 02 并列，周日收两条） |
| 4 | `04_月度复盘.md` | `0 20 28-31 * *` | 月末 28-31 日 20:00 | 月度复盘（agent 内部验证是否真月末） |

## 关于本地文件访问

云端 Claude agent **不一定**能读到你本地磁盘上的 `~/Desktop/哲学史/备考规划/` 文件。因此每个 prompt 都按两种情况设计：

- **若能读到本地文件**：自动读取当周计划、当日日志、图谱，生成详细任务清单
- **若读不到**：输出一份"通用提醒 + 当日该关注的事项"，依靠 prompt 内置的节奏表

**如何确保本地文件可访问**（三种方案，择一即可）：

1. **推荐**：把 `备考规划/` 推到一个私人 GitHub repo，触发器 prompt 里改成 `gh clone`。这样云端 agent 能读到最新内容。
2. **备用**：把关键状态（当周计划、最近 3 天日志）复制粘贴到每次触发器运行的"注入上下文"（每周一手动更新一次 prompt 的注入块）。
3. **最简**：接受"只推送通用提醒"，把详细任务生成留给自己每天早上手动打开 Claude Code。

**建议先用方案 3 试 1-2 周**，体验一下提醒的节奏是否合适，再决定要不要升级到方案 1。

## 创建触发器的操作步骤（待 /schedule 连接恢复）

对每个触发器文件：
1. 用 `/schedule` 命令
2. 选 "创建新触发器"
3. 把对应 `.md` 文件里的 `Prompt:` 块完整粘贴
4. 设置 cron 为文件顶部的 `Cron:` 值
5. 推送目标选 Claude App（mobile push）
6. 保存

## 推送到 Claude App 的注意事项

- 推送长度有上限，所以 prompt 让 agent 生成的内容保持在 **500 字以内**
- 详细任务清单（如需要）让 agent 写入本地文件（若能），推送只给摘要 + 文件路径
- 若当天任务很多，让 agent 按"今日必做 + 可选"分层

## 手动测试建议

创建完后，用 "run now" 各跑一次，把结果截图保存到 `推送样本/` 目录（之后再建），以便调优 prompt。
