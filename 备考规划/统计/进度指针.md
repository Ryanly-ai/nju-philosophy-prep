## 顺延规则（晨间触发器逻辑）

每天 08:00 晨间触发器执行：

1. 读取昨日日志（`每日日志/YYYY-MM/前一天.md`）
2. 判断昨日是否完成：
   - 文件不存在 → **未完成**
   - "专业课实际用时" 字段为空 / `__` / `0` → **未完成**
   - "专业课实际用时" ≥ 1 分钟 → **完成**
3. 推进指针：
   - 昨日**完成** → 指针 +1（D7 → 下周 D1）
   - 昨日**未完成** → 指针不动（今日继续做昨日内容）
4. 从周计划文件读指针对应段，作为今日"今日任务"
5. 在本文件"历史轨迹"表追加一行，更新"当前指针"

**特殊情况**：
- 起跑日（指针首次启用）按本文件初始值
- 周计划某 D 不存在 → 用阶段通用任务并标记 `⚠️ 周计划未找到`
- 昨日是"⏸ 调整规划日" → 视为完成（不消耗计划日，但指针 +1）
