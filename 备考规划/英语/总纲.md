## Phase 1 学习方法（已选定）
**不用单词 App**，改用 Claude 生成"考研真题风格短文 + 词表 + 测验"模式：
- 每日一篇 ~250 词短文，含 20 个新词（加粗） + 8-10 个螺旋复习老词
- 配套词表（拼写 / 音标 / 词性 / 中文 / 文中原句）
- 5 题速记测验 + 隔日抽查（D-1 / D-3 / D-7 / D-15 / D-30）
- 错词加权：测验答错的词 3 天内必再出现
