#### 2. 子思子的五行理论主要阐述的内容是什么？

	1、五行是指仁、义、礼、智、圣
	2.“德之行”与“行”的区别：
		德之行—— 形于内，发自内心的自觉，属于形而上的天道
		行——形于外， 只是为了迎合外界的规范，并非发自内心，属于形而下的人道
		下学上达，内圣外王，内收与外扩的区分
	3.一心三思：仁之思、智之思、圣之思
		仁之思的特点是精细，在体，内化的德气流于颜面和四肢；
		智之思的特点是长久，在眼，发现贤人的美德，和礼教相关
		圣之思的特点是轻盈，在耳，和乐道相关，“闻君子道，聪也。闻而知之，圣也。”

#### 3.《中庸》的主要思想是什么

	1.关于天命的阐述
		“天命之谓性，率性之谓道，修道之谓教
		天命是万物得以生存、创造的根本原理
	2.戒惧慎独：
		“道也者，不可须臾离也，可离非道也。是故君子戒慎乎其所不睹，恐惧乎其所不闻。莫见乎隐，莫显乎微。故君子慎其独也。”
		天命之性是超越的大本，至隐至微，所以人必须以戒惧的心情来奉持之
	3.中和
	“喜怒哀乐之未发，谓之中；发而皆中节，谓之和。中也者，天下之大本也； 和也者，天下之达道也。致中和，天地位焉，万物育焉。
		中：情感未发之前，心寂然不动，没有过与不及的弊病，这种状态叫“中”。“中”是道之体，是性之德。
		和：情感抒发合于中道，恰到好处，无所乖戾，自然而然，这就叫做“和”。“和”是道之用，是情之德。“和”是道之用，是情之德。

#### 4.《中庸》主要思想 · 应试苏格拉底法训练卡（2026-05-11）

##### 4.1 考场调用场景预判

- **原文钉子（最高频）**：
	- 「天命之谓性，率性之谓道，修道之谓教」（开篇三句）
	- 「喜怒哀乐之未发谓之中，发而皆中节谓之和」
	- 「诚者，天之道也；诚之者，人之道也」
- **概念支点**：中庸 / 诚 / 慎独 / 致中和 / 天命之性
- **论证链条**：性—道—教 / 中和—位育 / 诚—贯通天人
- **思想史连接**：思孟学派（传为子思）→ 朱熹列入"四书"，成为宋明理学骨架
- **可能题型**：名词解释（中庸 / 诚 / 慎独）、简答（《中庸》的天人观或工夫论）、论述（《中庸》在思想史上的地位）

##### 4.2 可背诵的论述题答案（约 400 字）

> 《中庸》传为子思所作，是思孟学派的代表作，后被朱熹列入"四书"，成为宋明理学的重要思想源头。
>
> **【开篇骨架】** 开宗明义曰：「**天命之谓性，率性之谓道，修道之谓教**」——天所赋者为性，循性而行为道，修道立教以化天下，由此建立"由天而性、由性而道、由道而教"的天人贯通骨架。
>
> **【中和论】** 进而言：「**喜怒哀乐之未发谓之中，发而皆中节谓之和**」。"中"为天下之大本（性之本体），"和"为天下之达道（性之发用），故曰「**致中和，天地位焉，万物育焉**」。
>
> **【工夫论】** "致"之之道，在「**戒慎乎其所不睹，恐惧乎其所不闻**」与「**慎独**」——于人所不知而己所独知之地，戒慎不令一念之私滑过。
>
> **【诚论】** 《中庸》后半以"诚"为最高范畴：「**诚者，天之道也；诚之者，人之道也**」——诚为天道本然（真实无妄），诚之为人当行之工夫。圣人「**自诚明**」是为"性"，贤人「**自明诚**」是为"教"，须由「**博学、审问、慎思、明辨、笃行**」五步而至，"人一己百、人十己千"，则**虽愚必明，虽柔必强**。
>
> **【至诚境界】** 至诚之人，能**尽己性、尽人性、尽物性，赞天地之化育**，终至「**与天地参**」——人与天地并立为三，臻天人合一之极境。
>
> **【思想史意义】** 《中庸》上承孔子"中庸"之德、下接孟子心性之学，将儒家修身工夫上提至"天人合一"的形上高度，奠定了宋明理学"性—诚—天理"一系的核心理论框架。

##### 4.4 全部易错点清单（共 20 条）

**🔴 最大失分模式**

1. **🚩 "后世术语提前回塞" · 四连击**：复性 / 私欲蒙蔽 / 知行合一 / 去蔽。
	→ 卡顶警戒线："先秦不用：体用、复性、私欲蒙蔽、知行合一、去蔽、理一分殊、心即理 / 性即理。"
2. **🚩 "自然 / 正常"系列泛词**：自然流露 / 自然反应 / 平和 / 严格要求 / 顺应天命。
	→ 卷面替换：中节 / 合于道 / 戒慎恐惧 / 检束 / 推而极之。

**🟡 字义训释错误**

3. 中 ≠ 折中，是"不偏不倚、无过无不及"。
4. 中 ≠ 平和，是"喜怒哀乐之未发、寂然不动"。
5. 庸 ≠ 仅指日常，要补"恒常不易"（程颐：不易之谓庸）。
6. 率 = 循、顺，不是"发挥"。
7. 致 = 推而极之，不是"达到"。
8. 审问 = 审慎询问，不是"反思"。
9. 明 = 明白万理，不是"行为合规"。

**🟡 出处与本体定位**

10. "反身而诚"是《孟子》，不是《中庸》。思孟相通 ≠ 出处可混。
11. 诚者 = 天之道（本体），不是"圣人之道"。
12. 诚之者 = 人当行之道（工夫），不是"常人之道"。
13. "大本" = 道德性情之根本，不是宇宙本原（不要套"太极""气"）。

**🟡 答题结构**

14. 回答"为什么"要引《中庸》原文（"道不可须臾离""莫见乎隐莫显乎微"），不要泛泛说"为符合天性"。
15. "性—教"必须呼应开篇"天命之谓性 / 修道之谓教"。
16. 层层递进的原文必须分层写（己—人—物—天地），不能压扁。
17. 论述题必须收"思想史意义"——思孟学派 / 四书 / 宋明理学之源。
18. 问什么答什么：问"靠什么工夫"，不要答"为什么有可能"。
19. 慎独的标准训释要背朱熹注："人所不知而己所独知之地"。
20. 错别字：独立"判"断（不是"间"接）。卷面错字逐一清理。
