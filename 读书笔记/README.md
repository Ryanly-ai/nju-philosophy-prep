# 读书笔记

每本**精读**书单独一个子文件夹。读到哪建到哪，不预先占位。

## 规范

- 文件夹名：`作者-书名`（避免重名，例：`郭齐勇-中哲史`、`陈鼓应-老子今注今译`）
- 子文件命名：`NN-章节名.md`（NN 两位数字，按书的原始章节顺序）
- 每本书首页：`00-索引.md`（MOC，汇总本书的关键概念 `[[]]` 双链）
- 笔记和 `参考书籍——markdown/` 的原文分离：原文只读，笔记可写

## 何时建一本书的文件夹

读完该书 **第一章** 且确实产出了值得沉淀的内容时再建。避免"空壳文件夹"心理负担。
