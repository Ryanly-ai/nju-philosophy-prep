# 苏格拉底教学法复习记录

这个目录用于记录每次用苏格拉底式问答复习后暴露出的易错点，方便后续在 Obsidian 中回看。

## 目录规则

- 一级目录按书本或课程主线划分，例如：
  - `中国哲学史/`
  - `中国哲学原著/`
  - `宋明理学/`
- 二级文件按章节或专题划分，例如：
  - `中国哲学史/孔子.md`
  - `中国哲学史/孟子.md`
  - `中国哲学史/老子.md`

## 每次记录格式

```markdown
## YYYY-MM-DD｜专题名

### 本轮卡片 / 知识点
- 

### 我容易犯的错误
1. 

### 应改成的考试表达
- 

### 下次复习优先纠正
1. 
```

## 使用原则

- 只记录真实暴露出的错误，不做泛泛总结。
- 每条错误都要配一个可替换的考试表达。
- 重点记录：概念混淆、时代错置、关键词堆叠、卷面表达不稳、原文使用不准。
